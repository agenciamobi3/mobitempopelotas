# Regional City Readiness

## Objetivo

Controlar a maturidade técnica, editorial e SEO antes da promoção de uma cidade regional.

O publication gate controla se uma cidade pode aparecer. O readiness controla se ela está pronta para avançar.

## Critérios

### Basic

- IBGE validado;
- coordenadas validadas;
- fonte meteorológica validada.

### Complete

Além dos critérios básicos:

- contexto hidrológico validado;
- conteúdo editorial pronto;
- SEO pronto;
- imagens prontas;
- FAQs prontas.

## Fluxo

candidate → draft → basic → complete

Uma cidade não deve ser promovida para indexação apenas por existir no cadastro.

## Uso

A camada é interna e deve apoiar futuras ondas de expansão regional sem impactar as 24 cidades atuais publicadas.
