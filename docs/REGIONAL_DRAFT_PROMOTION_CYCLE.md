# Regional Draft Promotion Cycle

## Objetivo

Registrar o primeiro ciclo controlado de promoção de uma cidade candidata sem alterar a superfície pública.

## Fluxo

candidate → approved → RegionalCity(draft) → basic → complete

## Regras

- A promoção para draft não publica a cidade.
- `coverage` deve permanecer como `draft`.
- `indexable` deve permanecer `false`.
- Sitemap e rotas públicas não devem ser alterados automaticamente.

## Primeira candidata avaliada

Arambaré é o primeiro caso de validação completa:

- identidade municipal validada;
- coordenadas validadas;
- meteorologia validada;
- evidência hidrológica direta registrada.

A promoção real deve continuar sendo uma decisão explícita e versionada.
