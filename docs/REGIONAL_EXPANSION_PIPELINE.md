# Regional Expansion Pipeline

## Objetivo

Definir o fluxo seguro para adicionar novos municípios ao Tempo Pelotas sem criar páginas públicas ou indexáveis antes da validação necessária.

## Fluxo

candidate

- análise interna;
- sem rota pública;
- sem sitemap;
- sem indexação.

↓

draft

- cadastro técnico iniciado;
- validação de dados oficiais;
- fora da superfície pública.

↓

basic

- página disponível para validação;
- fora do sitemap;
- noindex, follow.

↓

complete

- conteúdo validado;
- SEO validado;
- elegível para indexação.

## Critérios de promoção

Antes de uma cidade atingir complete:

- código IBGE validado;
- coordenadas conferidas;
- fonte meteorológica validada;
- contexto hidrológico avaliado;
- conteúdo editorial preparado;
- SEO preparado;
- imagens e elementos visuais disponíveis.

## Princípio

Adicionar uma cidade ao inventário não deve publicar automaticamente uma nova superfície. Toda expansão passa por validação técnica, editorial e SEO.
